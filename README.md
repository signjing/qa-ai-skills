# QA AI Skills

面向 QA / 测试场景的 AI Agent Skills 合集。每个 Skill 都用真实需求、真实项目验证过，不是纸面设计。发现的问题、踩过的坑、改坏过的版本，都记录在对应系列的文档里。

---
 
## 这是什么
 
我是一名 QA / 测试工程师，过去这段时间在探索一件事：**怎么把一个有经验的人的判断力，变成可复用的 AI 能力，然后让它在团队里真正起作用**。
 
需求评审是第一个落地的场景。围绕它写了一个 12 篇的系列，记录了从"一句话生成 MVP"，到 Prompt 工程、知识库、人格蒸馏，到能力边界划分、版本迭代、效果评测、团队推广的完整过程——不是精心挑选的成功案例，踩过的坑、跑偏的版本、迭代改坏的地方，都留在了文章里，📖 完整方法论和踩坑记录，详见 [讲透需求评审 Skill 系列合集](https://mp.weixin.qq.com/mp/appmsgalbum?__biz=MjM5NjA5MzIzNw==&action=getalbum&album_id=4596402718117953545&scene=21#wechat_redirect)

这个仓库，是把这套方法沉淀出来的 Skill 本体开源出来，同时也是这套方法论向其他场景（测试设计、技术评审、自动化测试、线上问题分析……）迁移的起点。
